Upload protection leads

Add protection leads in bulk from a spreadsheet, or restore a protection backup.

Save the spreadsheet as a CSV file (in Excel: File, Save As, CSV) with these column headings:

  • Date created: when the lead came in, e.g. 28/09/2026
  • Advisor: matched to a colleague by name; anyone not found comes in as Unassigned
  • Client: joint clients in one cell, separated by commas
  • Phone and Email (optional): any column with those headings is picked up too

You'll see a preview before anything is saved. To restore from a backup, choose a protection-lead-tracker-backup file instead; it's recognised automatically.

Daily backup

A full copy of every case, including audit trails, statuses and the Recycle Bin, saved as a CSV file that opens in Excel.

The first time you sign in each day, a backup file downloads automatically to this computer's Downloads folder. To restore, use Settings → Upload leads and choose a backup file. Cases are put back with their advisor, status and audit trail exactly as they were. Don't edit and re-save the file in Excel, as that can damage the backup column.

Send in Blue is backed up too: Management also get a send-in-blue-backup file each day (every case, its history and the Send in Blue Recycle Bin). If your browser asks whether this site can download multiple files, choose Allow. To restore it, use Restore from backup in the Send in Blue section of Settings.
